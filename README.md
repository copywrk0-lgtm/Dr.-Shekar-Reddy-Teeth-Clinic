# Dr. Shekar Reddy Teeth Clinic — Client Delivery Package

A production-oriented React/Vite dental clinic website based on the supplied source project. The original 27 source files are preserved and the project adds routing, custom 404, SEO/deployment files, lead capture hooks, Apps Script, documentation, analytics hooks, accessibility improvements and legal pages.

## Run locally

```bash
npm ci
npm run dev
```

## Production QA

```bash
npm run check
npm run preview
```

Before launch, replace `dentalclinicdrshekhar.vercel.app` in `index.html`, `public/robots.txt`, `public/sitemap.xml`, `public/` metadata and deployment documentation.

## Lead capture

Set `VITE_APPS_SCRIPT_URL` to the deployed Google Apps Script Web App URL. Without it, the site still prepares the WhatsApp appointment enquiry.

## Verified public claims used

The website uses a conservative `4.9★` / `1,100+ patient ratings` presentation. The exact Google review count is intentionally not presented as Google-specific because it was not directly retrievable during verification.

## Client verification still required

Confirm the current clinic phone number, exact opening hours, doctor credentials, Google Business Profile URL, holiday hours, service claims and all published photographs before launch.
